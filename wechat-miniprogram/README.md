# 听音背单词微信小程序

这是微信小程序源码，可先用微信开发者工具的测试模式体验。正式发布前，需要使用你自己的小程序 AppID，并由你本人完成微信公众平台的主体信息、域名配置、代码提交和审核。

## 一、导入微信开发者工具

1. 在电脑上下载安装并打开“微信开发者工具”。
2. 使用微信扫码登录开发者工具。
3. 在首页选择“小程序”，再点击“导入项目”。
4. “项目目录”选择整个 `wechat-miniprogram` 文件夹。不要只选择其中的 `pages` 文件夹。
5. 只在电脑本地模拟器中初次查看界面时，可以使用项目已有的 `touristappid` 游客模式；需要调用在线服务时可改用测试 AppID。
6. 项目名称可填写“听音背单词”，然后点击“导入”。

## 二、仅供预览的测试设置

游客或测试模式下，在线词典请求可能被域名校验拦截。仅在初次本地预览时，可以点击开发者工具右上角“详情”，打开“本地设置”，临时勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”。

这个选项只用于开发预览，不能代替正式发布所需的合法域名配置。如需让命令行工具执行编译，请在开发者工具中依次打开“设置” -> “安全设置”，开启“服务端口”，然后保持开发者工具运行。

## 三、在 iPhone 上预览

真机二维码预览前，必须把项目改为测试 AppID，或者改为扫描二维码的微信账号有开发或体验权限的正式 AppID。`touristappid` 只用于电脑本地模拟器，不能依赖它进行 iPhone 二维码预览。

1. 在开发者工具中确认首页可以打开。
2. 点击顶部“预览”，等待生成二维码。
3. 使用 iPhone 上已登录的微信扫描二维码。
4. 在微信中打开预览版，测试添加、查询、播放、显示答案和备份恢复。

游客模式或测试号适合初步体验，但不能直接作为正式上线的小程序。

## 四、正式 AppID 和合法域名

正式发布时，请先在微信公众平台注册小程序，完成主体信息，再取得正式 AppID。随后在开发者工具的项目设置中把 `touristappid` 换成你的正式 AppID。

登录微信公众平台，在“开发”相关设置中配置服务器域名。把下列 HTTPS 域名按实际用途加入 `request` 合法域名和 `downloadFile` 合法域名：

- `https://freedictionaryapi.com`
- `https://api.mymemory.translated.net`
- `https://dict.youdao.com`

微信公众平台可能要求校验域名所有权，第三方公共域名也可能不允许直接加入。如果遇到这种情况，需要把查询或音频请求转发到你自己备案、可验证的 HTTPS 服务域名，再把该自有域名配置到微信公众平台。不要在正式版本中依赖“关闭合法域名校验”。

完成配置后，由你本人在开发者工具中上传代码，并在微信公众平台填写版本说明、隐私和主体资料，提交微信审核。审核通过后仍需由你本人点击发布。

## 五、日常使用

1. 打开“词库”，在“英语单词”中输入单词，点击“自动查询”。
2. 核对美式音标和中文释义。查询失败时，可以手动填写音标和释义后直接保存。
3. 点击“保存到词库”。在词库列表中可以播放、编辑或删除单词。
4. 切换到“复习”，先点击“播放美音”；听不出来时点击“显示答案”，会显示单词、美式音标和中文释义。
5. 点击“下一个”继续，并可选择随机或顺序复习以及播放语速。

查询结果来自在线服务，保存前应自行核对。小程序会优先选择明确标注为美国英语的音标和音频；没有可靠结果时会提示手动确认，不会把不明口音冒充美音。

## 六、备份与恢复

1. 在“词库”底部点击“复制备份”，把备份文字保存到微信收藏、备忘录或其他可靠位置。
2. 恢复时，把完整备份文字粘贴到备份输入框。
3. 点击“粘贴导入”。导入前不要随意修改备份内容。
4. 建议在清空词库、换手机或重新安装前先复制备份，并实际测试一次能否导入。

## 七、验收清单

- [ ] 输入 `tool` 并点击“自动查询”，显示美式音标 `/tul/` 和中文释义“工具”。
- [ ] 保存 `tool` 后，可在词库列表播放美音。
- [ ] 在“复习”中先隐藏答案，点击“播放美音”后再点击“显示答案”。
- [ ] 点击“下一个”时，旧单词的声音会停止，界面与读音不会错位。
- [ ] 关闭小程序后重新打开，已保存的词条仍然存在。
- [ ] “复制备份”后清空词库，再通过“粘贴导入”恢复词条。
- [ ] iPhone 微信预览中，音标始终从左向右显示，没有颠倒。
